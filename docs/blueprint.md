# **App Name**: FactoryConnect

## Core Features:

- Product Listing: Allow factories to list their products with detailed specifications, images, and pricing.
- Marketplace Browsing: Enable users to browse and search for products based on categories, keywords, and filters.
- Contact Factory: Enable users to message the factories in order to make inquiries, powered by the LLM which acts as a tool for suggesting common business inquiries.
- Request for Quote (RFQ): Allow buyers to submit RFQs to multiple factories and compare quotes.
- Seller Dashboard: Provide sellers with a dashboard to manage their product listings, track orders, and view analytics.
- Private Chat Box: Every user can chat privately with the seller of a specific product about the pricing and other details

## Style Guidelines:

- Primary color: Deep Indigo (#3F51B5) to convey professionalism and trust.
- Background color: Light Gray (#F0F2F5), to maintain a clean and modern aesthetic.
- Accent color: Sky Blue (#03A9F4) to highlight key interactive elements, drawing attention in a positive way.
- Body text: 'Inter', a sans-serif font that offers a clean, neutral, and highly readable appearance, perfect for displaying technical product details.
- Headline font: 'Space Grotesk' for a bold, modern and slightly technical feel to titles.
- Use clean, minimalist icons to represent product categories and actions, for easy recognition.
- Implement a grid-based layout to ensure a structured and responsive design across different devices.
- Keep the app in a dark theme and light theme as per user reference - have options to switch between
