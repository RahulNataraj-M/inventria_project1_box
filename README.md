# Digital Platform for Industrial By-Product Reuse

A digital platform that connects **large-scale industries with small-scale industries** to facilitate the reuse of industrial by-products.

The platform enables industries to **list, discover, and exchange by-products**, helping turn industrial waste into useful resources while promoting a circular economy.

## Features

* List and manage industrial by-products
* Discover available by-products
* Connect industries for reuse opportunities
* Simple and responsive web interface
* Firebase-based data management

## Tech Stack

* **Next.js**
* **React**
* **TypeScript**
* **Firebase**
* **Tailwind CSS**

## 🎯 Objective

To reduce industrial waste by creating a digital marketplace where **by-products from one industry can become useful raw materials for another**.
